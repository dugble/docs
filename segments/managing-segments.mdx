---
title: Managing Segments
description: Create, inspect, list, and delete reusable audience segments.
---

Segments are named audience containers. They are intentionally simple: create the segment, then manage its contact memberships separately.

## Create a segment

```bash
curl --request POST \
  --url https://api.dugble.com/segments \
  --header "Authorization: Bearer $DUGBLE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "name": "Pro customers"
  }'
```

A segment name is required and cannot be empty.

## List segments

```http
GET /segments?limit=50&offset=0
```

Segment listing uses offset pagination. The limit is capped at 100.

## Retrieve a segment

```http
GET /segments/{segment_id}
```

The segment resource includes its ID, team ID, name, and creation time.

## Inspect members

Use:

```http
GET /segments/{segment_id}/contacts
```

This returns the contacts currently assigned to the segment.

## Delete a segment

```http
DELETE /segments/{segment_id}
```

Deleting a segment removes the grouping, not the underlying contact records.
