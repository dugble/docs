---
title: Managing Contacts
description: Create, retrieve, update, list, and delete contacts with Dugble.
---

Contacts are team-scoped recipient profiles. Use the contact API when you need a durable record that can participate in topics, segments, broadcasts, and campaigns.

## Create a contact

```bash
curl --request POST \
  --url https://api.dugble.com/contacts \
  --header "Authorization: Bearer $DUGBLE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "email": "ada@example.com",
    "first_name": "Ada",
    "last_name": "Lovelace"
  }'
```

The email address is required. If a phone number is supplied, it must be a valid international number.

## Retrieve and list contacts

Retrieve one contact by UUID:

```http
GET /contacts/{contact_id}
```

List contacts with offset pagination:

```http
GET /contacts?limit=50&offset=0
```

The list endpoint accepts a maximum `limit` of 100 and uses 50 when the limit is omitted or outside the accepted range.

## Update a contact

Use `PATCH /contacts/{contact_id}` to change profile fields, consent state, unsubscribe state, or custom properties.

```json
{
  "first_name": "Augusta Ada",
  "properties": {
    "plan": "enterprise"
  }
}
```

Updating `properties` replaces the contact's property object with the supplied object.

## Unsubscribe state

The `unsubscribed` field represents the contact's email unsubscribe state. Keep it separate from topic-level preferences and SMS consent; each represents a different messaging decision.

## Delete a contact

```http
DELETE /contacts/{contact_id}
```

Deleting a contact removes the profile from the team. Use deletion only when you intend to remove the contact rather than simply unsubscribe or suppress the recipient.

<Warning>
Dugble rejects a create or update that would produce a duplicate email address or phone number within the team.
</Warning>
