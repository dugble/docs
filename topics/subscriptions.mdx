---
title: Managing Subscriptions
description: Read and update a contact's topic subscription preferences.
---

Topic subscriptions let each contact opt into or out of specific message categories without changing the topic itself.

## List a contact's topics

```http
GET /contacts/{contact_id}/topics
```

The response includes each topic and the contact's effective `subscription` value:

```json
{
  "object": "list",
  "has_more": false,
  "data": [
    {
      "id": "49a3999c-0ce1-4ea6-ab68-afcd6dc2e794",
      "name": "Product updates",
      "description": "Major releases and announcements",
      "subscription": "opt_in"
    }
  ]
}
```

This endpoint uses cursor pagination with `after` or `before`. Do not send both cursors in the same request.

## Update subscription states

Use `PATCH /contacts/{contact_id}/topics` with an array of topic updates:

```bash
curl --request PATCH \
  --url https://api.dugble.com/contacts/$CONTACT_ID/topics \
  --header "Authorization: Bearer $DUGBLE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '[
    {
      "id": "49a3999c-0ce1-4ea6-ab68-afcd6dc2e794",
      "subscription": "opt_out"
    }
  ]'
```

Each update must use `opt_in` or `opt_out`.

## Defaults and overrides

A topic's `default_subscription` determines the initial behavior for contacts that have not recorded an explicit preference. A contact-specific subscription update provides the contact's effective preference for that topic.

<Note>
Use topics for preference management. Use segments when you need an explicit audience group for targeting.
</Note>
