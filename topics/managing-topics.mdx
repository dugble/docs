---
title: Managing Topics
description: Create, retrieve, update, list, and delete subscription topics.
---

Topics define the message categories that contacts can subscribe to or opt out of.

## Create a topic

```bash
curl --request POST \
  --url https://api.dugble.com/topics \
  --header "Authorization: Bearer $DUGBLE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "name": "Product updates",
    "description": "Major releases and announcements",
    "default_subscription": "opt_out",
    "visibility": "public"
  }'
```

Topic names can be up to 50 characters and descriptions up to 200 characters. `default_subscription` must be `opt_in` or `opt_out`. Visibility can be `public` or `private`.

## List topics

The public API uses cursor pagination:

```http
GET /topics?limit=20
```

Use `after` or `before` to navigate through the list. Do not combine both cursors in one request.

## Update a topic

You can update the topic's name, description, and visibility:

```json
{
  "name": "Platform updates",
  "visibility": "public"
}
```

The topic's `default_subscription` is not part of the update model, so choose that behavior carefully when the topic is created.

## Delete a topic

```http
DELETE /topics/{topic_id}
```

Deleting a topic removes the preference category itself. Applications should stop referencing the deleted topic ID in contact subscription updates.
