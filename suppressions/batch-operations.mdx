---
title: Batch Operations
description: Add or remove up to 100 suppressions in a single request.
---

Use the batch suppression endpoints when you need to apply the same suppression operation to many recipients at once.

## Add suppressions

```bash
curl --request POST \
  --url https://api.dugble.com/suppressions/batch/add \
  --header "Authorization: Bearer $DUGBLE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "emails": [
      "ada@example.com",
      "grace@example.com"
    ]
  }'
```

A batch must contain between 1 and 100 valid email addresses. If one or more addresses are already suppressed, the operation returns a conflict response.

## Remove by email

```bash
curl --request POST \
  --url https://api.dugble.com/suppressions/batch/remove \
  --header "Authorization: Bearer $DUGBLE_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "emails": [
      "ada@example.com",
      "grace@example.com"
    ]
  }'
```

## Remove by suppression ID

```json
{
  "ids": [
    "49a3999c-0ce1-4ea6-ab68-afcd6dc2e794",
    "6df09499-503d-4771-b8a0-727acf341a2e"
  ]
}
```

Provide either `emails` or `ids`, but not both. Each list can contain up to 100 values.

## Response data

Batch add returns the IDs of the created suppressions. Batch remove returns deletion objects for the suppressions that were removed.

<Note>
Batch endpoints reduce HTTP overhead, but each suppression still represents an individual recipient address and retains its own ID and origin.
</Note>
